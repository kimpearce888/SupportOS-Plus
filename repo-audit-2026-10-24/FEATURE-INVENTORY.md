## Background / integration / persistence / lifecycle (FEAT-003)

- **Boot order** (main.rs:13–173): logging init → `migrate_legacy_data_dir` → panic hook (`logs/fatal.log`, main.rs:29) → flock `instance.lock` (exit 1 on failure) → SQLite open + ALL boot migrations (`open_db`, main.rs:43–51) → log_level from settings → EventBus → `build_boot_services` (sync engine + provider; real w/ Help Scout creds, empty otherwise) → VectorIndex (DB setting `qdrant_enabled` default true, lazy store, main.rs:72–80) → `WorkersHost::start` (fatal + exit 1 on failure) → loopback listener (warn-only on failure) → eframe window; `SPP_SMOKE=1` short-circuits to headless smoke and exits before any window.
- **Workers**: see C-WORK-001..010 (job_loop 2s; auto_sync adaptive 30s→ceiling; maintenance 6h; stale_job_sweep 10min; notification_sweep 15s; customer_event_sweep 60s; intelligence_sweep 15min; connector_refresh 30s; one-shot start recovery). Drop ordering: workers host stops manager + joins runtime on drop (workers_host.rs:146–155); settings restart re-arms timers in-session (`WorkersHost::restart`, workers_host.rs:136–143).
- **Event bridge**: thread `spp-task-bridge` on EventBus broadcast; queue + repaint; drain in `logic_pass` each frame; heartbeat repaint 1.5s (app.rs:572). Routing table C-BRIDGE-001..005.
- **Loopback listener** (main.rs:100–134): `LoopbackServer::start` serves `POST /webhook`, `GET /oauth/callback` (log line main.rs:122); port = redirect-URI port → `SPP_LOOPBACK_PORT` → 0 (OS-assigned, logged); bind failure = `tracing::warn!` + `None`, app fully usable (webhooks recovered from DB at worker start).
- **Single instance**: `flock(LOCK_EX|LOCK_NB)` on `<data_dir>/instance.lock`, held for process lifetime, released on drop/exit; second instance → fatal log + exit 1, no IPC/focus handoff (single_instance.rs:1–7).
- **Theme persistence**: settings key `"theme"` (`"light"`/`"dark"`), default Light, unknown → Light; loaded at boot (app.rs:120), stored by 3 toggle surfaces (C-APP-005/006/009), applied via `ctx.set_theme` (theme.rs:77–82).
- **DB/migrations**: all boot migrations applied inside `spp_shell::open_db` before any UI; `schema_version` surfaced on Shell page (`latest_version` or 0, app.rs:123–128, 373); `db_path` or `"<in-memory>"` displayed.
- **Shutdown**: `_lock`/`_workers`/`_loopback` held to end of `main`; WorkersHost Drop = oneshot shutdown → `manager.stop()` → thread join; lock released automatically; run() error → `fatal::fatal` + exit 1 (main.rs:166–172).
- **Toasts lifetime model**: burn only on rendered passes, cap 1.6s/pass (toasts.rs:26,133–147) — hidden-window safe (item 69).
- **Palette search**: synchronous per-keystroke `db.with_read(search::search(conn, q, "all", default filters))` — web's 200ms debounce/generation race replaced by fast local query (palette.rs:180–199).
