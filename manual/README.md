# manual/ — the archived 1.8.0 handover snapshot

The four documents in this folder (Developer Handover and User Handbook,
each as HTML + PDF, plus the cover preview) are the **original v1.8.0
handover set**, kept for history: they were the deliverables that
transferred the project at the 1.8.0 milestone.

**They are a period snapshot, not current documentation.**

- Their UI descriptions predate the 1.9.0 design reskin (and every
  release since), so screens they show no longer match the app.
- The **current** user manual is [`USER_MANUAL.md`](../USER_MANUAL.md)
  at the repository root — re-stamped and maintained per release.
- The **current** developer-facing truth is the source itself
  (`crates/`), `README.md`, `CHANGELOG.md` and the ledger in `ai/`.

Nothing in the build reads this folder; it exists so the original
handover artifacts stay available. Do not cite it for current behavior —
cite `USER_MANUAL.md` instead.
